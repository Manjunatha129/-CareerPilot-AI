# Java & Spring Boot Technical Interview Preparation Guide

## 1. Spring Boot Core Architecture
Spring Boot simplifies Java enterprise application development through auto-configuration, starter dependencies, and embedded servers (Tomcat/Jetty).

### Key Concepts:
* **Dependency Injection (DI)**: Inversion of Control (IoC) container manages bean creation and lifecycles via `@Autowired` or constructor injection.
* **Spring Security & JWT**: Stateless authentication standard using JSON Web Tokens.
* **Spring Data JPA**: Repository abstraction layer built over Hibernate ORM.

## 2. Java 21 Key Features
* **Record Patterns & Pattern Matching**: Enhances concise data transfer object (DTO) declarations.
* **Virtual Threads (Project Loom)**: Lightweight threads that significantly increase concurrency throughput for I/O bound applications.
* **Sequenced Collections**: Introduces a uniform interface for collections with defined encounter orders.
