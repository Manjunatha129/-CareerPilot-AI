# Resume Optimization & ATS Standards Guide

## 1. Resume Structuring for Applicant Tracking Systems (ATS)
Modern companies use Applicant Tracking Systems (ATS) to parse, index, and score resume submissions before human recruiters review them.

### Best Practices:
* **Action-Result Bullet Points**: Frame accomplishments using the Google X-Y-Z formula ("Accomplished [X] as measured by [Y], by doing [Z]").
* **Standard Headers**: Use clear section headers like `Work Experience`, `Technical Skills`, `Education`, `Projects`.
* **Keyword Matching**: Incorporate exact technical keywords and skill names (e.g. Java, Spring Boot, React, PostgreSQL) matching the target job description.
* **Format Stability**: Use standard clean PDF formats without complex multi-column tables or embedded images.
